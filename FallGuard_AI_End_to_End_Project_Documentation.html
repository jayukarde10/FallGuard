1. High-Level Executive Summary

FallGuard AI is an automated, privacy-preserving video monitoring system tailored for elderly care facilities, hospitals, and assisted-living environments. Falls represent the leading cause of accidental injury and mortality in older adults. Conventional wearable alarms often fail due to poor compliance (dementia, forgetting to wear them, or battery drain), while standard CCTV cameras severely breach human dignity in bedrooms and private quarters.

FallGuard AI solves both dilemmas simultaneously through a dual-branch neural architecture:

  1. Spatiotemporal Action Recognition: Evaluates temporal velocity and posture shifts across 16-frame rolling video buffers using a 3D-CNN (C3D) and calibrated binary classification head.
  2. Autonomous Privacy Shield: Employs OpenCV 5.0 YuNet DNN to detect faces in real-time, enforcing irreversible privacy filters (Gaussian, Mosaic, Solid Blackout, Frosted Glass) with custom safety boundary padding before video is stored or shown.
  3. Fall Kinematics Classification: Uses dense Farneback optical flow to differentiate forward, backward, sideways, and sudden collapse dynamics without requiring invasive sensors.

Step 2 Color Space Conversion (BGR to RGB)

OpenCV's BGR format is converted to RGB via cv2.cvtColor(frame, cv2.COLOR_BGR2RGB). This is required because pre-trained C3D convolution kernels and web browsers expect RGB channel ordering.

Code Location: C:\Users\Jay\AIML_FallDetection_jay\video_pipeline.py (Lines 160-175)
Step 3 Spatial Downsampling to 112 x 112 Pixels

Frames are resized to $112 \times 112$ pixels using bilinear interpolation (cv2.INTER_LINEAR). This exact resolution satisfies the spatial dimension constraints of C3D's 5 max-pooling stages ($112 \rightarrow 56 \rightarrow 28 \rightarrow 14 \rightarrow 7 \rightarrow 4$). Any other resolution causes dimension mismatches at the FC6 linear layer.

Code Location: C:\Users\Jay\AIML_FallDetection_jay\video_pipeline.py (Lines 180-195)
Step 4 Temporal FIFO Rolling Window Buffer (16 Frames)

A First-In-First-Out (FIFO) queue keeps exactly 16 consecutive frames. When frame $t$ arrives, it is appended; once the length reaches 17, frame $t-16$ is popped. This ensures $O(1)$ constant memory usage (~600 KB RAM) without leaking memory during continuous 24/7 monitoring.

Code Location: C:\Users\Jay\AIML_FallDetection_jay\video_pipeline.py (Lines 200-225)
Step 5 Channel-Wise Mean Subtraction Normalization

The buffer is converted to a float32 array and centered using Sports-1M pretraining channel means: clip_arr = clip_arr - np.array([124.0, 117.0, 104.0], dtype=np.float32). Centering values around zero accelerates feature convergence and matches original C3D activation statistics.

Code Location: C:\Users\Jay\AIML_FallDetection_jay\video_pipeline.py (Lines 230-245)
Step 6 Tensor Dimensional Permutation

PyTorch requires channels-first 3D convolutional format: (Batch, Channels, Time, Height, Width). The array of shape (16, 112, 112, 3) is transposed to (3, 16, 112, 112) and unsqueezed to (1, 3, 16, 112, 112).

Step 7 Dataset Metadata Interval Cleaning & Parsing

Ground truth CSV annotations in GMDCSA24 (e.g. "Falling (SW)[3.4 to 6]; Sitting[0 to 3.4]") are parsed with regular expressions into clean timestamps and boolean fall flags for verification.
